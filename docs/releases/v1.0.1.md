# Google Lens API v1.0.1

This release adds an optional `ai_overview` field to completed search results.
The Scrapling worker extracts it only when the page exposes an explicit Google
AI Overview heading and adjacent answer text. If the page does not expose a
clearly identifiable overview, the field is omitted.

Visual matches remain separate, independently observed result listings. The
overview is generated text and must not be treated as a verified display
identification. Challenge handling remains terminal and does not bypass
Google's verification pages.

The API response change is backward-compatible and needs no database migration.
Automated checks use local fixtures and mocks; they do not make live Google
searches or paid AI requests.
