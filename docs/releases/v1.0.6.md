# Google Lens API v1.0.6

This release prevents Redis Streams from reclaiming normal, still-running Lens
searches after only five seconds. The default reclaim idle window is now two
minutes and configuration is rejected if that window is less than the bounded
browser timeout plus a 30-second margin. Redis result writes are first-writer-
wins, so a late duplicate terminal response cannot replace the first result.

The production Compose file exposes the reclaim setting as
`LENS_RECLAIM_IDLE_MS` with the safe default. Existing Redis, image, and RMA
database volumes are unchanged. All new checks use offline tests and do not
contact Google or paid recognition services.
